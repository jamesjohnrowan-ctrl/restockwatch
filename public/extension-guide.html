Connect your retailer tabs

Use your regular Chrome or Edge browser. Keep a separate product tab for every listing you want to monitor: two console tabs and two controller tabs. All four monitors run independently while your computer is awake and the browser, tabs and local tracker remain running.

Update your existing extension

Open chrome://extensions (or edge://extensions) and click Reload on ReStockWatch. Version 1.2 adds the controller monitors. Your console selections are retained. The update uses the same retailer permissions.

First-time installation
  1. On your browser’s Extensions page, enable Developer mode and choose Load unpacked.
  2. Select this folder:

    the extension folder inside your ReStockWatch project

Console tabs

  • EB Games · Console ↗ — select this listing in the extension using Monitor EB tab.
  • Staples Canada · Console ↗ — select this listing in the extension using Monitor Staples tab.

Controller tabs

  • EB Games · Controller only ↗ — select this listing in the extension using Monitor EB controller.
  • Staples Canada · Controller only ↗ — select this listing in the extension using Monitor Staples controller.

Let each product page’s normal security check finish. While viewing that tab, open ReStockWatch from the browser’s Extensions menu and click its matching monitor button. Starting a controller monitor does not stop its console monitor.

The controller + display stand bundle is Nintendo Store exclusive and is checked by the local tracker; it does not need an EB Games or Staples tab.

Check that it is running

Each monitor in the popup should say Monitoring selected tab, then show a last read, a last result, a next reload and Delivered to local tracker. The corresponding product/version on the dashboard should update from Waiting. Each tab reloads after a new random 4–6 minute wait; an initial read uses the page already open. Results older than nine minutes become Unknown.

If you close or navigate away from a selected product tab, its monitor stops. Reopen that exact listing and select it again. A blocked, timed-out or unknown reading is not a sellout and does not create stock history.

The extension reads only the selected product tabs’ titles, product names, stock labels and ordering-button states. It does not export cookies or personal tabs, click checkout or solve security challenges. Actual restock/sellout detection remains unverified until a real inventory transition happens.
